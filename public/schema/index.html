8-Bit Oracle Schema Documentation

This documentation describes the JSON Schema definitions used by 8-Bit Oracle for hexagram divination data and its persistence in the OriginTrail Decentralized Knowledge Graph (DKG).

Available Schemas

1. Hexagram Schema

Defines the structure for I-Ching hexagrams in the 8-Bit Oracle system.

View Hexagram Schema

Example Hexagram Usage

{
  "@type": "hexagram:Hexagram",
  "hexagram:number": 5,
  "hexagram:binary": "010101",
  "hexagram:name": {
    "chinese": "需",
    "pinyin": "Xu"
  },
  "hexagram:lines": [
    {
      "number": 1,
      "value": 7,
      "changed": false
    }
    // ... remaining lines
  ]
}

2. Divination Schema

Defines the structure for complete divination readings, including market context and interpretation.

View Divination Schema

Example Divination Usage

{
  "@type": ["CreativeWork", "divination:Reading"],
  "@id": "urn:hexagram:5",
  "name": "Xu - 需 - Waiting",
  "dateCreated": "2024-03-26T12:00:00Z",
  "author": {
    "@type": "Person",
    "identifier": "@user123"
  },
  "divination:context": {
    "marketSentiment": {
      "Telegram": {
        "current": "positive",
        "24 hours ago": "negative",
        "7 days ago": "negative"
      },
      "Reddit": {
        "current": "highly positive",
        "24 hours ago": "highly positive",
        "7 days ago": "highly positive"
      },
      "General market": {
        "current": "highly positive",
        "24 hours ago": "positive",
        "7 days ago": "positive"
      }
    },
    "newsEvents": [
      "Mt. Gox, the bankrupt Japanese crypto exchange, made a $1 billion Bitcoin transaction, sparking speculation among creditors about potential payouts.",
      "Over half of U.S. states have introduced Bitcoin reserve bills, with Wisconsin leading by becoming the first state to invest in Bitcoin ETFs."
    ],
    "interpretation": "The market shows strong positive momentum across multiple platforms, with particularly bullish sentiment on Reddit..."
  }
}

Integration with OriginTrail DKG

These schemas are used to structure knowledge assets in the OriginTrail DKG. The structured format enables:

  • Semantic querying of divination history
  • Temporal relationship tracking between readings
  • Market context preservation
  • Standardized data exchange

Schema Versioning

The current schema version is 1.0.0. Any breaking changes will be reflected in the schema version number following semantic versioning principles.
